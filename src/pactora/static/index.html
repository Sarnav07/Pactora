Privacy with explicit limits.

The model sees your request and its proposed choices. Wallet data, approval and receipt secrets stay outside its tools. Merchants still see their orders; network and account correlations can remain.

MVP: native Zcash regtest and a controlled test merchant. No redeemable goods. Live ZEC-funded Bitrefill settlement is disabled. FROST is a separate protocol proof.

Private receipt vault

Receipts are encrypted to this browser’s device key. Reveal and export them from Live. Losing browser storage loses access; exports contain encrypted receipts, not a backup of your device key.

Revealed content clears when you switch tabs or lock this view. Browser extensions, screenshots and an agent with browser access can still expose it.

What the model knows

A hosted model receives your prompt, candidates and proposed choice. Skills cannot erase a transcript or prevent a client’s memory hooks from saving those messages. Private information must never enter the tools’ responses.
